# Field Marketing

A static site with three pages, switched from the menu boxes at the top:

- **Sales**: a chart of leads coming in with events, the events hosted (left), a form to add each event (right), and links to the HubSpot lead lists.
- **Recruitment**: a chart of candidates hired with events, recruiting events, an add form, and links for finding researchers.
- **Branding**: merch shown like a shop (picture, inventory, sizes), an "Add more" form for new merch or ideas, then Design system, Figma and Branding materials links.

Everything you add is saved in your browser (localStorage). The example events and links are placeholders to replace.

Run locally with `python3 dev-server.py 8140` and open http://localhost:8140, or open `index.html` directly.
